2. 자바스크립트 기초 문법

var: 함수 스코프, 재선언 가능, 호이스팅 시 undefined 초기화.

let: 블록 스코프({}), 재할당이 가능하고 재선언이 불가하다.

const: 블록 스코프({}), 재할당 불가능하다. 

- 블록스코프란?
중괄호 {}가 만드는 벽

재할당 여부 중요하니까 참고


데이터 타입 및 연산자

== (단순히 값만 같은거): 값만 비교 (자동 형변환 O, 1 == '1' true).

=== (모두 같은지): 값과 타입 모두 비교 (1 === '1' false).


특수 값: NaN (숫자 아님), undefined (값 할당 안 됨), null (의도적 빈 값).

3. 배열과 객체
배열 메서드 (Helper Methods)

forEach: 배열을 돌면서 출력하거나, 외부 변수에 값을 누적할 때 사용

map: 배열의 요소를 변형해서 새로운 배열을 만들 때 사용

filter: 조건이 true인 요소만 모아 새로운 배열 반환.

주의: push, pop, reverse, sort 등은 원본 배열을 변경함.

ES6 문법

전개 구문 (...): 배열/객체의 요소를 풀어서 복사하거나 합칠 때 사용 (얕은 복사이므로 참고).

구조 분해 할당: const { age } = user; (객체 속성을 변수로 추출).



4. 함수와 제어문
함수 정의

여기서 호이스팅이란?
- 변수와 함수의 선언문을 스코프의 최상단으로 끌어올리는 것처럼 동작하는 현상을 말한다.


선언식: function a() {} (호이스팅 O).

표현식: const a = function() {} (호이스팅 X).

화살표 함수: const a = () => {} (간결함, this 바인딩 다름).

반복문 (for)

두개 비교하는 부분 지난번 시험에도 나온 부분

for...in: 객체의 Key (속성) 순회.

for...of: 반복 가능 객체(배열 등)의 Value (값) 순회.

This

일반 함수: 호출한 대상에 따라 결정 (전역 호출 시 window).

화살표 함수: 함수가 선언된 시점의 상위 스코프 this 고정 (Lexical scope).
